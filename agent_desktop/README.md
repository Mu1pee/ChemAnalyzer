# Agent Desk

Обновлённый тёмный интерфейс: `dist/agent-desk/AgentDesk.exe`.
Графитовые панели, боковая навигация, бирюзовые основные действия, разделённые
этапы работы и прокрутка журнала/диалога. Оба режима используют прежние клиенты.
Для сборки этой версии используйте команду ниже.

Небольшой Windows-клиент с двумя независимыми режимами:

- ChemAnalyzer: запуск исследовательского backend, загрузка FreeSolv, импорт
  собственных QSAR/других исследовательских задач, обучение, отмена и прогноз.
- ИИ-помощник: локальная модель Ollama, диалог, работа с выбранным текстовым
  файлом и составление планов. Это текстовый помощник, без выполнения команд ОС.

Запуск: `dist/agent-desk/AgentDesk.exe`. Клиент автоматически ищет работающий
ChemAnalyzer по процессам backend и проверяет локальный API. Кнопка
«Найти ChemAnalyzer» повторяет поиск. При доступном Research Lab клиент
подключается к найденному экземпляру. Версия и адрес отображаются в окне.
Если найденная версия приложения не поддерживает Research Lab, кнопка
«Запустить движок» запускает исследовательский backend из `build/research-backend`.
Для запуска собственного backend EXE должен находиться внутри папки проекта.
Научные библиотеки и модели не встраиваются повторно в маленький клиент.

Собственный backend хранит данные в `%LOCALAPPDATA%/ChemAnalyzerAgent`.
При подключении к работающему экземпляру используются его задачи и модели.
При выходе закрывается только запущенный клиентом backend; текущая задача,
запущенная этим клиентом, отменяется. Подключённый ChemAnalyzer продолжает работу.
Показан реальный этап обучения, без фиктивных процентов. Модели experimental,
автоматического утверждения нет. Для CSV нужны конфигурация задачи и provenance
из AI_AGENT_USER_GUIDE.md. FreeSolv при первом импорте требует интернет.

Для универсального помощника нужен уже установленный и запущенный Ollama с
загруженной моделью. Нажмите «Найти модели», выберите модель, введите задачу.
API: http://127.0.0.1:11434. Клиент не загружает модели автоматически и не
передаёт текст внешним API. Подключение к localhost само по себе не гарантирует
локальное исполнение: выбирайте локальную модель, а не облачный профиль Ollama.
Ошибка подключения/отсутствие модели отображается явно; ответы не имитируются.
[Протокол Ollama](https://github.com/ollama/ollama/blob/main/docs/api.md).
Диалоги хранятся в оперативной памяти, файлы читаются только после выбора.

Исходники: `python agent_desktop/main.py` (Python с Tkinter).
Сборка из корня:

```powershell
$agentIcon = (Resolve-Path -LiteralPath assets/icon.ico).Path
.\backend\.venv\Scripts\python.exe -m PyInstaller --noconfirm --onefile --windowed --name AgentDesk --icon $agentIcon --distpath dist/agent-desk --workpath build/agent-desk --specpath build agent_desktop/main.py
```

Расширение: добавляйте отдельные клиенты инструментов в core.py и вкладки в
main.py. Текстовый помощник и ChemAnalyzer используют независимые фоновые задачи.
