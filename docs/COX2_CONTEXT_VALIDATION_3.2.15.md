# COX-2: отдельный белок человека, 3.2.15

После исправления смешения экспериментальных контекстов сохранённая модель
COX-2 прошла предусмотренные критерии ретроспективной внутренней проверки:
сбалансированная точность **76,22%**, ROC-AUC **0,8222**, MCC **0,5240**.
Это исследовательский прогноз IC50 <=1000 нМ в тестах на белке человека.
Результат не подтверждает антидотное действие, эффект в клетках, крови или
организме и не является новой независимой внешней валидацией.

Причина пересмотра — исходный фильтр учитывал человеческую мишень, тип B и
confidence 9, но эти признаки не отделяют тесты отдельного белка от опытов
на клетках и тканях. В прежнем курированном наборе были 2289 измерений с
аннотацией single protein, 343 клеточных, 208 тканевых и 25 с неопределённым
форматом. Категории относятся к измерениям; одна структура могла иметь
несколько измерений в разных контекстах.

Новый профиль требует Homo sapiens на уровне теста и BAO_0000357, исключает
заполненные поля клеток, тканей, фракций и вариантов белка. Описания с
упоминанием крови выделяются для отдельной проверки, даже если структурные
поля ошибочно указывают single protein. «Cell-free» само по себе не является
причиной исключения. Аннотация формата не доказывает совпадение субстратов,
времени инкубации или методов детекции — это остаётся ограничением модели.

Проверены контрольные суммы замороженного снимка ChEMBL 37: 981 тест в
каталоге, 6027 исходных строк активности. По метаданным совместимы 719 тестов;
реальные данные итоговой таблицы происходят из 298. Отдельно отмечены 203
теста с другим/неизвестным форматом, 46 клеточных/тканевых/фракционных
контекстов и 13 описаний, требующих разбора. Итог: 2111 уникальных структур,
1112 активных и 999 неактивных, 735 каркасов, 2146 измерений. Пропуски не
превращались в отрицательные метки. Единицы, значения и ID итоговых измерений
повторно сверены с исходными записями.

План сохранён до обучения: seed 42, разбиение целыми нехиральными каркасами
Мердока, фиксированные RF/LR/gradient boosting. Validation выбирает модель
по PR-AUC среди прошедших критерии. Выбран RF с 200 деревьями, одним потоком
CPU и sigmoid-калибровкой только внутри train по трём scaffold-folds. Test не
выбирает модель, порог или seed. Сохранён именно проверенный train-only объект;
после теста он не переобучался. Данные прежнего смешанного набора уже
использовались в предыдущих экспериментах, включая обучение на всей панели;
история разработки явно указана в плане. Новое разделение не следует
называть нетронутой внешней проверкой.

Проверка загруженного артефакта заново воспроизвела test-метрики на свежих
признаках. 95%-й описательный интервал BA по 5000 bootstrap-повторениям целых
каркасов: **71,18–80,85%**. Он рассчитан для отчёта, без подбора модели.
Из 422 test-структур 273 имеют Tanimoto >=0,5 к train, 110 — от 0,3 до 0,5,
39 — ниже 0,3. Вне области применимости приложение скрывает численный прогноз.

Прежняя внутренняя проверка с ROC-AUC 0,733 и внешний эксперимент с BA 56,77%
сохраняются как неудачные результаты. Внешние 62 соединения в новом запуске
не использовались ни для обучения, ни для выбора, ни для новой оценки.
Качество на произвольных новых сериях и условиях остаётся непроверенным.
