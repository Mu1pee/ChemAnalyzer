# Внешняя проверка COX-2: модель отклонена

18 ноября 2026 года проведён новый зафиксированный эксперимент. Модель
обучена на 2740 ранее подготовленных соединениях ChEMBL37 и проверена на
62 других структурах: 30 активных и 32 неактивных. Сбалансированная точность
составила **56,77%**. Требование выше 60% не выполнено; модель в приложение
не подключалась, нового установщика по результатам этого эксперимента нет.

| Показатель | Результат | Условие |
| --- | ---: | --- |
| Сбалансированная точность | 0,567708 | > 0,60 |
| ROC-AUC | 0,591667 | >= 0,75 |
| MCC | 0,137955 | >= 0,25 |
| Average precision | 0,607062 | > базовых 0,483871 |
| ROC-AUC при перемешанных обучающих метках | 0,491333 | <= 0,60 |

Матрица ошибок: 15 верно распознанных неактивных, 17 ложноположительных,
10 ложноотрицательных и 20 верно распознанных активных. 95%-й интервал
сбалансированной точности при 5000 повторениях bootstrap по целым каркасам
Мердока: **40,25–72,31%**. Для уверенного вывода о качестве данных недостаточно.

Новые данные содержат 35 каркасов, отсутствующих во всём прежнем наборе.
Совпадения структур и известных DOI прежнего набора исключены. Использованы
версионированные экспорты BindingDB за ноябрь 2026 года и семь соединений из
[Alshaye и соавт., Molecules 2024, 29, 1309](https://doi.org/10.3390/molecules29061309).
Лицензии сохранены для каждой строки: CC BY 3.0 или CC BY 4.0.

Структуры новой серии сверены с названиями, схемами, формулами и массами;
названия разобраны OPSIN, формулы проверены RDKit. Шесть соединений с уже
известными каркасами исключены. Также исключены 10b с несогласованными
формулой/массой и 10e/10f с переставленными численными значениями в таблице
и обсуждении. Флуоресцентный тест ADHP из исходного пула не включён в этот
эксперимент. Пропущенным результатам не присваивалась метка неактивности.

План и уточнение названия существующего параметра `balanced_subsample`
сохранены до обучения. Использован один ранее выбранный случайный лес:
200 деревьев, seed 42, один поток CPU, калибровка только на обучающих данных
с разбиением по каркасам. Новый тест не использовался для выбора алгоритма,
порога или параметров. Предыдущая неудачная внутренняя проверка COX-2
остаётся в истории. В новом эксперименте прежние внутренние validation/test
явно включены в обучение; внешняя проверка использует другие данные.

У 16 из 62 новых структур сходство с обучающими примерами составляет
Tanimoto >= 0,5; у 45 оно находится в диапазоне 0,3–0,5 и у одной ниже 0,3.
Есть различия протоколов и зависимость состава классов от публикации.
Результат не доказывает качество на произвольных молекулах. Этот набор уже
использован для оценки: последующую настройку по его результатам нельзя
выдавать за независимую проверку.

[План, измерения, прогнозы, протоколы и отчёт](evidence/cox2-external-pilot-2026-11-18/README.md)
сохранены вместе с контрольными суммами. Отдельный пересчёт матрицы ошибок,
сбалансированной точности, MCC и попарного ROC-AUC подтвердил числа отчёта.
Код приложения и действующие модели этим экспериментом не изменены.
Цель качества каждой системы пока не достигнута; этот опыт не оценивает
антидотное действие против парацетамола или рост первичного корня растений.
