# Локальная база ChEMBL

ChemAnalyzer может открыть точную карточку соединения и измерения из
официального выпуска ChEMBL 37 в SQLite. Для этого база должна быть заранее
установлена на компьютере. Запросы к API и сохранённые профили приложения
доступны и без локальной базы.

1. Скачайте `chembl_37_sqlite.tar.gz` и `checksums.txt` из каталога выпуска
   [EMBL-EBI ChEMBL 37](https://ftp.ebi.ac.uk/pub/databases/chembl/ChEMBLdb/releases/chembl_37/).
   Архив занимает 5,76 ГБ. Для архива и распакованной базы нужно около 37 ГБ
   свободного места.
2. Проверьте архив командой
   `Get-FileHash -Algorithm SHA256 -LiteralPath 'chembl_37_sqlite.tar.gz'`.
   Контрольная сумма этого выпуска
   `33c203740555f96067710cdfc1c3c55d890660e5908ec5cbf5817492c290d281`.
3. Извлеките файл `chembl_37/chembl_37_sqlite/chembl_37.db`. В Windows поместите
   базу в папку данных приложения `chembl\chembl_37.db`, либо задайте полный
   путь к файлу через `CHEMANALYZER_CHEMBL_SQLITE` в окружении процесса или в
   `.env` в папке данных приложения. База открывается только для чтения.

При отказе точного онлайн-поиска либо ошибке первой страницы измерений
приложение может обратиться к базе по полному InChIKey. Полный подходящий
профиль из онлайн-кэша сохраняет приоритет. Если API сообщил, что совпадений
или измерений нет, либо вернул часть измерений, эти результаты сохраняют
своё происхождение. Локальная запись другого ChEMBL ID не заменяет
подтверждённое онлайн совпадение.

Вкладка показывает выпуск и дату локальной базы. В профиль входят имя,
экспериментальные измерения IC50, Ki, Kd, EC50 и Potency, показания и механизмы.
Приложение читает до 2000 измерений в порядке activity_id и указывает
число найденных и загруженных строк. Таблица мишеней использует строки
с pChEMBL, как в онлайн режиме. Поиск аналогов требует API.

Файл базы распространяет EMBL-EBI. Данные ChEMBL предоставлены участниками
ChEMBL и EMBL-EBI под [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
