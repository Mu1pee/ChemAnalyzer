# Независимые тесты в AI Research Lab

Откройте «Записать независимую проверку», выберите зарегистрированную модель
и загрузите JSON. Реестр привязывает отчёт к SHA-256 файла весов и проверяет,
что SHA-256 набора отличается от обучающего. Повторная загрузка того же
отчёта сохраняет одну запись. Иная версия отчёта с той же контрольной суммой
набора требует отдельной проверки источника.

Для допуска модель должна пройти собственный отложенный тест и все
добавленные независимые тесты. При новом обучении лаборатория дополнительно
применяет те же критерии к той части отложенного теста, для которой модель
показывает прогноз. Область применимости строится только по обучающей части.
В отчёте видны метрики всего теста и поднабора, базовые результаты,
число молекул и каркасов. Недостаток данных в поднаборе блокирует допуск,
даже если метрика на полном тесте выше порога.

Оценки отдельных источников видны в карточке.
Результат ниже порога сохраняется и блокирует исследовательский прогноз,
рецензию и активацию. Реестр также применяет проверку к ранее одобренным
моделям при следующем запросе прогноза. Для существующих записей без внешних
отчётов и отдельной оценки в области применимости действует решение по
исходному отложенному тесту. Карточка отмечает отсутствие отдельной оценки.

Отчёт готовит куратор по совместимому экспериментальному набору с
достаточным числом молекул и каркасов. Перечисленные ниже поля фиксируют
сведения куратора. Само приложение проверяет привязку и числовые критерии.
Пересечение молекул, сопоставимость эксперимента и происхождение измерений
проверяют при подготовке отчёта.

## Формат JSON

Ниже условный пример структуры. Для импорта подставьте измеренные метрики
и реальные контрольные суммы. В `scope` укажите `applicability_domain`,
если метрики посчитаны на молекулах в области применимости модели, или
`whole_cohort` для всей выборки.

```json
{
  "source": "Название эксперимента, DOI или идентификатор базы данных",
  "protocol": "Краткое описание совпадения экспериментальных условий, разбиения и области применимости",
  "dataset_sha256": "bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb",
  "artifact_sha256": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "independent_of_development": true,
  "scope": "applicability_domain",
  "evaluation": {
    "test": {"r2": 0.72, "mae": 0.51},
    "baseline_test": {"mae": 0.89},
    "support": {"test": {"molecules": 45, "scaffolds": 30}},
    "test_used_for_selection": false
  }
}
```

Для классификации укажите в `test` поля `balanced_accuracy`, `roc_auc`
и `pr_auc`, в `baseline_test` поле `pr_auc`, а в `support.test` также
`negative` и `positive`. Минимум для каждого теста составляет 20 молекул
и три группы каркасов. Для классификации нужны как минимум 10 молекул
каждого класса. Базовый прогноз строится только на обучающих данных и
оценивается на тех же тестовых молекулах. Допуск использует R² > 0,60 и
снижение MAE для регрессии. Для классификации нужны сбалансированная
точность > 60%, ROC-AUC ≥ 0,70 и улучшение PR-AUC.

## Проверка на примере LogD при pH 7,4

Вторая модель обучена на 2 674 молекулах AstraZeneca из ChEMBL 37.
Объединение SVR и ядерной регрессии выбрано на 669 валидационных молекулах
по MAE. Значения из двух внешних источников открыли для оценки после
фиксации весов. Исторический отложенный набор AstraZeneca уже применялся для
оценки предыдущей модели, поэтому его результат служит сравнением.

| Набор | Молекул в области / всего | R² на всём наборе | R² в области | MAE в области |
| --- | ---: | ---: | ---: | ---: |
| AstraZeneca, исторический тест по каркасам | 621 / 836 | 0,637 | 0,696 | 0,504 |
| Литературный набор Wang и соавторов | 226 / 725 | 0,665 | 0,723 | 0,821 |
| Отдельная лабораторная серия ASAP/Bienta | 31 / 125 | 0,103 | 0,344 | 0,760 |

Литературный набор объединяет опубликованные измерения с общим pH.
В серии Bienta использован один протокол shake-flask. После исключения
неоднозначных повторов, пропусков, цензурированных значений и совпадающих
каркасов в ней осталось 125 молекул. Из 31 молекулы в области применимости
24 группы каркасов. Лабораторный результат ограничивает переносимость
модели. Реестр отклонил прогноз при добавлении этого результата.
Веса LogD остались в исследовательском каталоге на компьютере.
