CHEMANALYZER 3.2.0 — БЫСТРЫЙ СТАРТ (Windows)

Требования: Windows 10/11 x64, Node.js 24.20+, Python 3.12 x64.

1) Распакуйте ZIP полностью в обычную папку.
2) Откройте PowerShell в папке, где лежит package.json.
3) Выполните:

   .\scripts\build-windows.ps1

В результате в папке dist появятся установщик и portable EXE, если сборка
завершилась без ошибок.

Для разработки подробности находятся в README.md и DESKTOP_BUILD_GUIDE.md.

Важно: исходный ZIP не содержит уже собранный Windows EXE. Сначала нужно
выполнить сборку в Windows. Перед распространением обязательно проверьте
запуск на компьютере без установленного Python/Node.js.


Новый модуль ПК «Антидот-Прогноз»:
- открой вкладку «Антидот-Прогноз» после анализа молекулы;
- если моделей нет, приложение покажет статус «Модель не обучена»;
- шаблоны данных и инструкция обучения: backend/training/specialized_data/README.md.
